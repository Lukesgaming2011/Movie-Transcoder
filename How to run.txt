Library Studio 0.9.0

Run LibraryStudio.exe on Windows 10/11 x64. Python is included.
The updated Python source is Transcode_Movie_UI.py.

First use: Open Tool setup, download HandBrakeCLI or choose your existing command-line executable.
Movies: choose an MKV file/folder and destination. Choose Format / resolution, then Bitrate / quality.
Basic / High / HandBrake default / custom values appear for the selected format. Scan & preview, then Start.
Saved profiles and audio options are in Settings > Picture & sound. The DVD shortcut is removed.
Settings > Picture & sound: Automatic GPU preference, NVIDIA / AMD / Intel / Apple / CPU selection,
CPU fallback, and responsive CPU mode. Audio and filters can still use CPU with a GPU encoder.
DVD 480p remains; DVD 576p is removed. Original Quality copies the complete MKV without loss.
Movie year lookup, bonus features, surround audio, CD ripping, themes and animations are retained.
Activity: save troubleshooting logs, with local paths removed before sharing.

For GitHub: extract LibraryStudio-0.9.0-GitHub-source.zip and upload the extracted source contents.
MIT license, README, tests, native build script and Windows/macOS/Linux GitHub Actions workflow included.
Publish LibraryStudio-0.9.0-Windows-x64.zip as the Windows download in a GitHub Release.
The Windows executable runs only on Windows. macOS/Linux need native builds or Python source;
their support is not yet verified on native machines. Audio CD ripping is Windows only.
Automatic tool downloads are Windows x64 only; other systems choose installed native tools.
No movie files, personal settings or downloaded HandBrake/FFmpeg binaries are included in the public ZIPs.

Conversion progress shows estimated time left for the current file and whole queue.
Estimates appear after a few seconds and adjust with speed; elapsed time appears at completion.

Polished animations share a frame timer and retain their visible position when updated.
The queue summarizes total source size; scanning shows activity. Reduce motion is in Settings.
